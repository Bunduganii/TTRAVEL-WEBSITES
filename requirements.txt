# Travel Agency System Requirements

## Project Overview
A full-stack travel agency management system with customer portal, agent portal, and admin dashboard.

## Technology Stack
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Backend: Node.js
- Database: SQL (MySQL/MariaDB)
- Server Framework: Express.js

## Node.js Dependencies
- express: ^4.18.2
- mysql2: ^3.6.0
- body-parser: ^1.20.2
- cors: ^2.8.5
- dotenv: ^16.3.1
- bcryptjs: ^2.4.3
- jsonwebtoken: ^9.0.2

## Installation Steps
1. Install Node.js (v16 or higher)
2. Install MySQL/MariaDB database server
3. Run: npm install
4. Create database using schema.sql
5. Update .env file with database credentials
6. Run: node server.js
7. Open browser to http://localhost:3000

## Features
- User Authentication (Customer/Staff/Agent)
- Flight Search and Booking
- Hotel Search and Booking
- Package Tours
- Payment Processing (Zaad, E-Dahab, Credit Card)
- Customer Dashboard
- Agent Portal
- Admin Dashboard
- Booking Management

## Database Requirements
- MySQL 8.0+ or MariaDB 10.5+
- Database name: travel_agency
- See schema.sql for table structure
