  QUICK SETUP FOR NEW INSTALLATION (After Downloading from GitHub)
═══════════════════════════════════════════════════════════════

STEP 1: Install Dependencies
─────────────────────────────
npm install

STEP 2: Setup Database
──────────────────────
1. Start MySQL in XAMPP
2. Open phpMyAdmin: http://localhost/phpmyadmin
3. Create database: Click "New" → Name: travel_agency_db → Create
4. Import schema: Click travel_agency_db → Import → Choose schema.sql → Go

STEP 3: Find Your MySQL Password
─────────────────────────────────
Run this command:
  node test-db-connection.js

This will test common passwords and tell you which one works!

STEP 3.5: Verify .env File (If getting "access denied" error)
───────────────────────────────────────────────────────────────
Run this command:
  node check-env.js

This will check if your .env file is set up correctly!

STEP 4: Create .env File
─────────────────────────
Create a file named: .env (with the dot at the beginning)

Copy this content:
──────────────────
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password_here
DB_NAME=travel_agency_db
PORT=3000
JWT_SECRET=secret123

Replace "your_password_here" with the password from Step 3
(If no password works, use: DB_PASSWORD=)

STEP 5: Start Server
─────────────────────
npm start

You should see: ✅ Database connected successfully

STEP 6: Open Browser
─────────────────────
Go to: http://localhost:3000

═══════════════════════════════════════════════════════════════

❌ ERROR: "Access denied database"?
────────────────────────────────────
→ Run: node test-db-connection.js to find your password
→ Update .env file with correct password
→ See SETUP_NEW_INSTALLATION.md for detailed help
