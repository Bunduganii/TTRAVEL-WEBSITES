STEP 1: Create .env File
────────────────────────
1. In your project folder, create a NEW file named: .env
   (Just the dot and "env" - no extension)

2. Copy and paste this EXACT content:

───────────────────────────────────────────────────────────────
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=123
DB_NAME=travel_agency_db
PORT=3000
JWT_SECRET=secret123
───────────────────────────────────────────────────────────────

3. Save the file

IMPORTANT NOTES:
────────────────
✅ DB_PASSWORD= has NOTHING after the equals sign (empty password)
✅ NO quotes around values
✅ NO spaces around equals sign
✅ File name must be exactly: .env (with the dot at the beginning)
✅ Save in the same folder as package.json

VERIFY IT WORKS:
────────────────
Run: node check-env.js
Should show: ✅ DB_PASSWORD is set: (empty)
